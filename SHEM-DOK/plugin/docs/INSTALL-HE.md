# SHEM DOK - התקנה וחיבור

גרסה 1.0.1, בדיקות מעודכנות ל-16.10.2026.

החבילה מיועדת להתקנת SHEM בלבד. אינה משנה את SHIMI, אינה גובה תשלומים ואינה כוללת מפתחות סודיים. לא בוצעה התקנה בחנות חיה.

## דרישות והתקנה

- WordPress 6.5 ומעלה, PHP 8.1 ומעלה, WooCommerce פעיל, MySQL/MariaDB עם InnoDB.
- PHP: mbstring ו-gd. מומלץ memory_limit של 256M לפחות עבור מסמכים ארוכים.
- מעלים את ZIP התוסף דרך תוספים > תוסף חדש > העלאת תוסף ומפעילים.
- פותחים WooCommerce > SHEM DOK. נדרשת הרשאת manage_woocommerce.
- ברירת מחדל לאוטומציה: כבויה. מפיקים ובודקים מסמך ידני בסביבת בדיקה לפני הפעלה.
- אין צורך להשאיר מחשב או שיחה פתוחים. ההפקה מופעלת בתהליך PHP בשרת החנות.

## מסמך ידני

מזינים לקוח, פריטים ומחירים כולל מע״מ, הנחה בסכום ומשלוח. בוחרים אשראי או PayPal. אשראי שומר רק זיהוי ממוסך: ארבע ספרות אחרונות, מותג, שם, מספר תשלומים ואסמכתה. אין שדות למספר כרטיס מלא, תוקף או CVV.

מסמנים ברירת מחדל ליד שדה ושומרים. פרטי העסק וסעיפי משלוח נשמרים בשרת, לכל מערכת זו. מייל מנפיק לא נמסר ולכן נשאר ריק. הכותרת היא חשבונית עסקה. שני שדות זמני אספקה ומשלוחים פתוחים.

לחיצה על הפקה מקצה מספר ומייצרת PDF אמיתי שנשמר בארכיון. עריכה ושמירה מארכיון מעדכנות את אותו מספר עם בדיקת גרסה. הורדה חוזרת אינה מקצה מספר. מחיקה מוחקת את גוף המסמך וה-PDF לצמיתות מהמערכת; נשארת רק רשומת מספר/מפתח טכני שמונעת שימוש חוזר במספר או הפקה כפולה לאותה הזמנה. גיבויי שרת חיצוניים עשויים להחזיק עותקים לפי מדיניות האחסון.

## חיבור WooCommerce

התוסף מאזין ל-woocommerce_payment_complete ומוודא שההזמנה משולמת, במטבע ILS ועם אסמכתת עסקה. אין הפקה אוטומטית מהוספה לסל, הפניה בדפדפן או שינוי סטטוס בלבד. לאחר הפעלת האוטומציה, אירוע תשלום חדש מייצר מסמך אחד להזמנה. אירועים כפולים, הורדות ופתיחת הארכיון לא מייצרים כפילויות. אין הפקה רטרואקטיבית אוטומטית של כל ההיסטוריה.

רכיב הסליקה אחראי לוודא תשלום מול הספק לפני payment_complete. יש לבדוק את ה-gateway שלכם בסביבת sandbox. ייבוא הזמנה ידני מזהה את אותה הזמנה ומשתמש באותו מפתח, כך שלא נוצר מסמך אוטומטי כפול.

התוסף ממפה שורות מוצר, מק״ט, וריאציות, לקוח, תאריך, קופונים, הנחה, משלוח ואסמכתה דרך WooCommerce CRUD, עם תאימות HPOS. התמחור נשמר באגורות, וגם סכום המע״מ המקורי נשמר במקרה של הבדלי עיגול בין שורות. שינוי סכום ידני מבטל את נתון המס המקורי ומחשב אותו מחדש. הזמנה עם מע״מ שאינו תואם לשיעור המוגדר נעצרת לבירור. במקרה של עמלות מיוחדות, מטבע אחר או אי התאמה מדויקת בסכום הוא עוצר ואינו מנפיק מסמך שגוי.

## פרטי אשראי ו-PayPal

שער שאינו מוכר לא יסווג אוטומטית כאשראי. קיימים מיפויים ראשוניים ל-stripe, woocommerce_payments, paypal ו-ppcp-gateway. יש לוודא שסוג התשלום בפועל תואם, ולהגדיר את מזהה השער המותקן אצלכם:

```php
add_filter('shem_dok_gateway_methods', function($methods, $order) {
    // Add only the exact gateway ID and confirmed method used by this order.
    // $methods['your_verified_gateway_id'] = 'card'; // or 'paypal'
    return $methods;
}, 10, 2);
```

פרטי תשלום שסומנו כברירת מחדל למסמך ידני אינם מועתקים להזמנת WooCommerce, כדי לא לייחס ללקוח חדש פרטי כרטיס של לקוח אחר. פרטים אלה מגיעים מהספק דרך המסנן בלבד.

שמות שדות האסמכתה הממוסכת משתנים בין ספקים. לא מנחשים שדות מטא ולא שומרים סודות בדפדפן. מתקין החיבור יכול להשתמש במסנן:

```php
add_filter('shem_dok_order_snapshot', function($snapshot, $order) {
    // Map only confirmed fields documented by your installed gateway.
    // $snapshot['last4'] = verified last four digits;
    // $snapshot['brand'] = card brand;
    // $snapshot['holder'] = cardholder or PayPal payer name;
    // $snapshot['paypalEmail'] = verified payer email;
    // $snapshot['installments'] = verified instalment count;
    return $snapshot;
}, 10, 2);
```

פרטים שלא סופקו על ידי הספק נשארים ריקים; לא ממציאים שם בעל כרטיס או ארבע ספרות. יש לקבוע ידנית/בברירת מחדל את שני טקסטי האספקה או למפות אותם במסנן משיטת המשלוח בפועל.

## ניסיונות חוזרים ותקלות

כשל מתועד במטא ההזמנה _shem_dok_error וביומן WooCommerce תחת shem-dok. יש עד שלושה ניסיונות חוזרים עם השהיה. אם Action Scheduler זמין משתמשים בו, אחרת WP-Cron. לניסיונות חוזרים אמינים כשהאתר ללא תנועה יש להגדיר runner/cron שרת ולהפעיל מעקב על משימות שנכשלו. התהליך הראשוני מתבצע בשרת גם ללא דפדפן פתוח.

PDF נשמר במסד הנתונים של WordPress ולא בספריית מדיה ציבורית. ההורדה זמינה למנהלים בלבד. שילוב באזור הלקוח או שליחת מייל אינם מופעלים בחבילה זו; נדרש endpoint מאומת לפי בעלות לפני הוספת קישור ציבורי/לקוח. אין לחשוף מפתחות Woo או קישורי ניהול ללקוח.

## הפעלה בטוחה והגירה

התוסף אינו מעביר או מבטל מסמכים של מנגנון חשבוניות אחר. לפני הפעלת הפקה אוטומטית יש לוודא שאותו אירוע אינו מפיק במקביל מסמך דרך תוסף אחר. אין לשנות מספור היסטורי. מספור SHEM DOK חדש מתחיל ב-7001, ומנוהל במסד אחד משותף להפקה ידנית ואוטומטית. לא להפעיל שני עותקי התקנה עם מספור נפרד עבור אותה סדרה.

גבו את מסד הנתונים לפני עדכון. קובץ ZIP הוא קוד, לא גיבוי המסמכים. התקנה, הפעלה, הגדרת הסליקה, הפעלת האוטומציה ובדיקת תשלום אמיתי מבוצעות על ידכם; החבילה לא מחברת חנות או חשבון חיצוני בעצמה.
