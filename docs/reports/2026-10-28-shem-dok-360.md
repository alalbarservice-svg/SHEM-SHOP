## Findings
- F1 (high): the React admin (/admin.html) does not embed SHEM-DOK. Filter scc_admin_issue_document has no add_filter in WP-PLUGIN or SHEM-DOK/plugin. On a paid order that SHEM-DOK already invoiced, React issue-document answers 409 (business details of the legacy template missing) and its PDF answers 404. If the legacy template were completed it would create a second, legacy-numbered document (code reading, not run). Fix: hook the filter to ShemDok::issue_for_order and make admin-50-documents read ShemDok::stored_pdf, behind owner approval.
- F2 (medium): staging had woocommerce_calc_taxes=no; SHEM-DOK refuses a VAT mismatch by design. Live must have WC taxes on with the 18% rate. Reverted to the observed value (no) after the tests.
- F3 (low): the harness assumed products T-1001..T-1003 and VAT on. staging-fixtures.sh now creates them and sets/restores VAT.
